# 🛒 Retail Sales & Profitability Analysis

> **Turning retail data into business decisions — one insight at a time.**

## 🔎 What is this project?

Retail businesses generate thousands of transactions, but raw transactions alone don't tell the full story.

This project explores retail sales data to answer a simple but important question:

### **"Where is the business making money — and where is it losing opportunities?"**

I built an end-to-end analytics workflow using **Excel, SQL/PostgreSQL, and Power BI** to clean, analyze, visualize, and interpret retail sales and profitability data.

---

## 🎯 Business Questions

Instead of only creating charts, this project focuses on business-oriented questions:

| Area           | Key Question                                    |
| -------------- | ----------------------------------------------- |
| 💰 Sales       | How is overall sales performance?               |
| 📈 Profit      | Which areas contribute most to profitability?   |
| 🏷️ Products   | Which products/categories perform best?         |
| 🌎 Regions     | Which regions are driving business performance? |
| 📅 Trends      | How does performance change over time?          |
| ⚠️ Performance | Where are the potential problem areas?          |
